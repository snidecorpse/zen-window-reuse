# Changelog

## 0.1.0 — 2026-11-11

- Focus an existing suitable Zen window on a subsequent argument-free launch.
- Restore a minimized window and allow reuse across Windows virtual desktops.
- Preserve cold launches, explicit new/private windows, kiosk mode, and URL dispatch.
- Add the unofficial `zen.window-reuse-on-launch` Boolean toggle.
- Provide verified archive rebuilding, build-specific backups, restoration, and dry preparation.
- Invalidate the browser code cache on the next cold launch; an archive change alone can leave cached original code active.
- Offer optional external-link preferences for a selected profile.
- Include automated fixtures, a Windows CI template, sharing instructions, and an upstream Settings proposal.

Manually verified with Zen 1.24.1b on Windows. Other versions require validation.
